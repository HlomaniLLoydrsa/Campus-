CAMPUS — EXPLORE CARD BACKGROUND IMAGES
========================================

These are the background pictures shown on the Explore page cards.
They are currently placeholder images (colored gradients with emoji).

TO USE YOUR OWN PICTURES:
Simply replace any of these files with your own image.
You can keep the .svg name OR replace with .jpg/.png — if you use a
different extension, update the "bgImage" path in:
    src/app/(app)/explore/page.tsx

FILES AND WHAT THEY ARE:
  wyr-bg.svg       -> Would You Rather card
  nhie-bg.svg      -> Never Have I Ever card
  ttol-bg.svg      -> Two Truths, One Lie card
  admirer-bg.svg   -> Secret Admirer card
  isawu-bg.svg     -> I Saw You card
  wingman-bg.svg   -> Wingman Mode card

RECOMMENDED IMAGE SIZE: 400 x 500 pixels (portrait, 4:5 ratio)

Tip: If an image fails to load, the card automatically falls back to
its colored gradient, so the layout never breaks.
